
# Meu Portfólio

Portfólio pessoal desenvolvido para apresentar meus projetos
acadêmicos, habilidades técnicas e evolução em desenvolvimento
de software.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Funcionalidades

- Layout responsivo
- Navegação entre seções
- Apresentação de projetos
- Links para GitHub e LinkedIn
- Formas de contato

## Executar localmente

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute `python3 -m http.server 8000`.
4. Acesse `http://localhost:8000`.
